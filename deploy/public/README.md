# Публичный вход online-education.fun

Caddy завершает TLS и проксирует запросы на локальный `127.0.0.1:8080`.
Публичный Nginx принимает только домен и localhost, доверяет forwarded-адресу
только из Docker-сети и передаёт приложениям проверенную схему `https`.
Настройки origin и защищённых cookie задаются Compose override-файлом.

С сервера, из корня проекта:

```sh
docker compose -f compose.yaml -f deploy/public/compose.public.yaml up -d
```

На VPS включены systemd-службы `online-gymnasium-public-route.service`
(маршрут и исходящий NAT для нового адреса) и `online-gymnasium-stack.service`
(запуск Compose). Текущий маршрут привязан к локальному адресу `10.247.0.105`;
при смене публичного IP у провайдера его необходимо перепроверить. Сертификат
и ключ Caddy сохраняются в Docker volume `public_caddy_data`: не удалять его
при обычном обновлении. Автозапуск после полноценной перезагрузки должен
проверяться отдельно в согласованное время.

Раздел `/internal/` закрыт на публичном Nginx. Публикация инфраструктуры
не создаёт демо-аккаунты и не подтверждает работу оплаты, всех сценариев или
обновлённого дизайна. Витринные демо-учётки (учитель/ученик/родитель) на сервере
используют публичный демо-пароль (портфолио-сайт, allowlist `.gitleaks.toml`)
и логинятся кнопками на `/login`; пароль демо-админа и прочие секреты
в публичную среду не попадают.
