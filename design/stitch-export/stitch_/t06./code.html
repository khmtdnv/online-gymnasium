№ 214, 215 • Параграф 9 DIGI-PEN-STREAM #08-45-12
№ 214. ОДЗ: x ≠ 3, x ≠ -3

\(\frac{x + 3}{x - 3} + \frac{x - 3}{x + 3} = \frac{10}{3}\)

Приводим к общему знаменателю \(3(x^2 - 9)\):

\(3(x + 3)^2 + 3(x - 3)^2 = 10(x^2 - 9)\)

\(3(x^2 + 6x + 9) + 3(x^2 - 6x + 9) = 10x^2 - 90\)

\(6x^2 + 54 = 10x^2 - 90 \implies 4x^2 = 144 \implies x^2 = 36\)

\(x_1 = 6; \quad x_2 = -6\) (оба корня удовлетворяют ОДЗ)
edit_note Заметка Соколовой

Корни найдены безупречно! Проверка сокращения выполнена.

№ 215.

\(\frac{2y - 1}{y + 2} - \frac{y + 3}{y - 2} = 1\)

Знаменатель: \((y + 2)(y - 2) \ne 0 \implies y \ne \pm 2\)

\((2y - 1)(y - 2) - (y + 3)(y + 2) = y^2 - 4\)

\(2y^2 - 5y + 2 - (y^2 + 5y + 6) = y^2 - 4\)

\(-10y - 4 = -4 \implies -10y = 0 \implies y = 0\)

Ответ: \(y = 0\)
